# Shared Notes

This body is written once and emitted unchanged for every harness
(`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `HERMES.md`, `ANTIGRAVITY.md`).

## House rules

- Prefer small, reversible changes.
- Run the test suite before declaring work done.
- Never commit secrets; read them from the environment.
- Record decisions in `docs/decisions/` so the next session can find them.
